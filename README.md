# Super Fighter Pixel Tool

繁體中文瀏覽器點陣圖編輯器，目前版本 **v26**。

## 開啟方式

下載此儲存庫 ZIP 並解壓縮，使用瀏覽器開啟 `index.html` 或 `Super_Fighter_Pixel_Editor_v26.html`。兩個檔案內容相同，無須安裝或建置。

## iPad 平移

點頂部「✋ 移動畫布」，再用手指或觸控筆拖動畫布。要繼續畫圖，切回「鉛筆」。平移只改變檢視位置，不會畫上像素。

## v26 更新

- 支援 iPad／Apple Pencil 繪圖和平移。
- 停用繪圖區長按選單，避免誤觸文字選取。
- 新增「更改畫布尺寸」及九宮格錨點，不縮放角色；縮小畫布會裁切。

## 功能

- 繪圖、橡皮擦、吸色、填色、水平翻轉、復原／重做。
- 自動擷取使用色盤，連動替換全圖顏色並保留透明度。
- 矩形框選、自由套索、移動、複製／剪下／貼上、選取區另存透明 PNG。
- 載入多張 PNG，自由排列、調整對比比例、選定圖片編輯、貼入編輯圖。
- 透明區可使用棋盤格、灰色、黑色、粉紅色或自訂預覽底色，不影響匯出透明度。
- 匯出 PNG、儲存及開啟 `.sfpixel` 專案。

## 快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| Space＋左鍵拖曳 | 平移畫布 |
| B | 鉛筆（先關閉移動畫布模式） |
| 1～5 | 1×～5× 縮放 |
| W | 吸色 |
| A／S | 上一色／下一色 |
| D／F | 筆刷變細／加粗（1～8 px） |
| M／L | 矩形框選／自由套索 |
| Ctrl／⌘＋C、X、V | 複製、剪下、貼上選取素材 |
| Esc | 取消選取 |

## 儲存注意事項

匯出 PNG 和儲存專案僅保存目前選定的編輯圖；其他 PNG 請分別切換儲存。頁面關閉後，未儲存的圖片與暫存素材不會保留。

開圖保留原始尺寸，大圖受裝置記憶體限制；「最近鄰縮放」寬高上限各為 2048 px。色盤最多擷取 256 種可見 RGB 顏色。

完整改版紀錄可在工具左側「目前版本 v26」展開查看。
